Overview-
Yoga & Wellness is a modern and responsive website designed to promote healthy living, mindfulness, and fitness.
The website provides users with information about yoga practices, wellness programs, and healthy lifestyle habits
through a clean and user-friendly interface.

Features-
Responsive design for desktop, tablet, and mobile devices
Modern and attractive user interface.
Interactive navigation menu.
Smooth scrolling and engaging layout.
Clean HTML, CSS, and JavaScript implementation.

Technologies Used-
HTML5
CSS3
JavaScript

Project Structure-

script.js

Purpose-
The purpose of this project is to create a professional wellness platform that encourages users to adopt a healthier
lifestyle through yoga, fitness, and mindfulness practices.
